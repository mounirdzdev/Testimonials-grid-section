This project is a responsive website developed using **HTML5** and **CSS3**.

## 📱 Responsive Design

The website was developed using a **mobile-first approach**.

The layout adapts to different screen sizes using CSS Grid, Flexbox, and media queries.

The main breakpoints were designed to support:

* 📱 Mobile devices
* 📲 Tablets
* 💻 Desktop screens

## 🎯 Development Approach

During this project, I focused on creating a flexible and maintainable CSS architecture.

I used **CSS variables** to centralize colors, spacing, and other design values:

```css
:root {
    --spacing-50: 0.25rem;
    --spacing-200: 1rem;
    --spacing-400: 2rem;
}
```

I also used `rem` units instead of relying heavily on fixed pixel values in order to make the layout more flexible.

For the layout, I used **CSS Grid** and **Flexbox** depending on the requirements of each component.

I also avoided unnecessary fixed heights to allow the content to adapt naturally to different screen sizes.
